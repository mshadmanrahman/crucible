# Code of Conduct

This project follows a short version of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## The short version

- Be respectful. Disagree with the argument, not the person.
- Assume good faith until you have evidence otherwise.
- Keep discussions grounded in the work. "This rubric has a gap" is useful. "You are wrong" is not.
- Harassment, personal attacks, and discriminatory language are not welcome in issues, PRs, discussions, or any project space.

## Enforcement

Reports go to the repository owner via GitHub. Responses may include private feedback, edits, or blocks depending on severity. The goal is to keep the project useful, not to run a courtroom.

## Scope

This applies to all project spaces and to public spaces when an individual is representing the project.
